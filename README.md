# 🏠 자라는 집 (Growing House)

내가 만든 프로그램(앱)들을 **식구**로 만들어, 옆에서 잘라 본 집 한 채에 방별로 살게 하는 개인용 가상 오피스예요.
방을 하나 추가하면 집에 방이 저절로 붙고, 층이 차면 위로 한 층 올라가요.

- **출근·퇴근·자유시간** — 식구들이 집에 들어오고, 일하고, 돌아다녀요.
- **🙋 나왔어** — 집주인이 현관으로 들어오면, 할 말이 있는 식구가 한 명씩 와서 알려줘요.
- **📌 쪽지 한 줄** — 누가 맡을지 안 골라도, 알맞은 식구가 쪽지를 가져가 할 일·알림으로 적어둬요.
- **할 일(업무·개인)·오늘 알림**, 끝낸 일만큼 자라는 거실 화분, 오늘·이번 주 기록 페이지
- **🏠 식구 들이기·관리** — 코드 없이 화면에서 내 앱 주소로 새 식구를 들이고, 방을 만들고, 옮겨요.
- **🎨 모습 바꾸기**, 방 자리 바꾸기(⇄), 실제 시각·날씨에 맞춘 창밖, 휴대폰 보기, 화면 모드 3종

모든 데이터는 **내 브라우저(localStorage)에 저장**돼요. 서버·데이터베이스·키가 없어도 바로 돌아가요.

## 시작하기 (3단계)

1. GitHub에서 **Use this template**를 눌러 내 저장소를 만들어요.
2. `company.config.ts`를 열어 내 집으로 바꿔요.
   - `COMPANY` — 집 이름, 아이콘, 처음 연 날
   - `ZONES` — 방 목록(방을 추가하면 집에 방이 붙어요)
   - `STAFF_LIST` — 식구 목록. 식구마다 `name`(이름), `role`(맡은 일), `zone`(사는 방), `url`(내 앱 주소)
   - `WEATHER` — 창밖 날씨를 가져올 위치
3. [Vercel](https://vercel.com/new)에서 내 저장소를 불러와 **Deploy**를 누르면 끝이에요. 환경변수는 필요 없어요.

내 컴퓨터에서 먼저 보고 싶다면(Node 22 이상):

```bash
npm install
npm run dev
```

http://localhost:3000 을 열면 돼요.

## 식구를 늘리는 두 가지 방법

- **화면에서**: 오른쪽 패널의 **🏠 식구 들이기·관리** → 이름·맡은 일·방·앱 주소를 적어요. 이 브라우저에 저장돼요.
- **코드에서**: `company.config.ts`의 `STAFF_LIST`에 한 명 추가해요. 모든 기기·모든 사람에게 똑같이 보여요.

모습은 집 안에서 식구를 누른 뒤 **🎨 모습 바꾸기**로 고르는 게 제일 쉬워요. 마음에 드는 모습의 `lpc` 값을 config에 옮겨 적으면 기본 모습이 돼요.

## 더 해보고 싶다면

- **여러 기기에서 같은 데이터**: `app/components/houseState.ts`·`useTodos.ts`·`useStaffAppearance.ts`가 저장을 맡고 있어요. 이 부분을 Supabase 같은 서버 저장으로 바꾸면 돼요(쓰기에는 꼭 비밀번호를 거세요 — 사이트가 공개되니까요).
- **입력창이 있는 새 식구**(예: 가계부): 입력창 컴포넌트를 만들고 `StaffEntry.action`에 새 값을 추가해요.
- **집 안 장면의 이름**: 집주인·단짝·박일해·일감이·짬짬이·달리미·냠냠셰프는 장면(나왔어·알림·할 일·달리기·식사 시간)에 이름으로 쓰여요. 이름을 바꾸면 `app/game/HouseWorld.tsx`의 `WHO`도 같이 바꿔 주세요.
- **데모 모드**: 환경변수 `NEXT_PUBLIC_DEMO=1`을 넣으면 처음 온 사람에게 예시 할 일을 채워 보여줘요.
