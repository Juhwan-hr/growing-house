# 🏠 자라는 집 (Growing House)

옆에서 잘라 본 작은 집이에요. 처음엔 **현관 하나**뿐이고, 방을 추가할 때마다 집이 한 칸씩 자라요
(층이 차면 위로 한 층, 더 차면 옆으로 한 칸). 내 프로그램(앱)들을 **식구**로 만들어 방마다 살게 할 수 있어요.

- 처음엔 현관에 **첫 식구**(예시)가 있어요. 이름·앱 주소를 바꿔 내 식구로 만들어 주세요.
- **출근·근무·자유시간·퇴근** — 식구들이 현관으로 들어오고, 자리에서 일하고, 집 안을 돌아다니고, 나가요.
- 식구를 누르면 **식구 카드**(앱 열기 · 🎨 모습 바꾸기 · 방 가까이 보기)
- 방 자리 바꾸기(⇄), 실제 시각·날씨에 맞춘 창밖과 하늘, 강아지·고양이, 📸 집 사진 남기기, 휴대폰 보기

서버·데이터베이스·키가 없어도 바로 돌아가요. 모습·방 자리처럼 화면에서 바꾼 건 그 사람 브라우저에만 저장돼요.

## 시작하기 (3단계)

1. GitHub에서 **Use this template**를 눌러 내 저장소를 만들어요.
2. `company.config.ts`를 열어 내 집으로 채워요.
   - `COMPANY` — 집 이름, 아이콘, 처음 연 날
   - `ZONES` — 방 목록. 하나 추가할 때마다 집에 방이 붙어요
   - `STAFF_LIST` — 식구 목록. `name`(이름), `role`(맡은 일), `zone`(사는 방), `url`(내 앱 주소)
   - `WEATHER` — 창밖 날씨를 가져올 위치
3. [Vercel](https://vercel.com/new)에서 내 저장소를 불러와 **Deploy**를 누르면 끝이에요. 환경변수는 필요 없어요.

내 컴퓨터에서 먼저 보고 싶다면(Node 22 이상):

```bash
npm install
npm run dev
```

http://localhost:3000 을 열면 돼요.

## Claude Code로 키우기 (추천)

코드를 몰라도 돼요. 이 저장소에는 Claude Code용 안내서([CLAUDE.md](CLAUDE.md))가 들어 있어서,
Claude Code로 내 저장소 폴더를 열고 말로 부탁하면 알아서 고쳐 줘요.

```bash
git clone https://github.com/<내-아이디>/<내-저장소>.git
cd <내-저장소>
claude
```

이렇게 말해 보세요.

- "업무방을 하나 만들어 줘"
- "내 가계부 앱(https://…)을 식구로 들여 줘. 이름은 ○○, 업무방에 살게 해 줘"
- "첫 식구를 내 러닝 기록 앱으로 바꿔 줘"
- "다 됐으면 커밋하고 push해 줘" — Vercel에 연결해 두었다면 push만으로 사이트가 바뀌어요.

## 식구 모습 고르기

식구를 누른 뒤 **🎨 모습 바꾸기**로 고르면 그 브라우저에 저장돼요. 모든 사람에게 같은 모습으로 보이게 하려면,
고른 모습의 `lpc` 값을 `company.config.ts`의 그 식구에게 옮겨 적으세요.
